# HarunDurakoglu.github.io

This repository hosts public privacy policy and support pages for mobile applications.

## GitHub Pages

In the repository settings, enable GitHub Pages with these publishing settings:

- Source: **Deploy from a branch**
- Branch: **main**
- Folder: **/ (root)**

No custom domain is configured.
