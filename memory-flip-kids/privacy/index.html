Memory Flip Kids

Kids memory matching game

Privacy

Privacy Policy

Effective date: September 15, 2026

Overview

This Privacy Policy describes the privacy practices of the current version of Memory Flip Kids. The app is intended for children and is designed to work without collecting or transmitting personal information.

Information and accounts

The current version of Memory Flip Kids:

  • does not require account creation;
  • does not collect personal data;
  • does not use analytics;
  • does not use advertising;
  • does not use third-party tracking; and
  • does not use artificial intelligence.

Local app data

Gameplay progress and settings are stored locally on the device. The app does not transmit gameplay or progress data to a server and does not use a backend.

Children's privacy

Memory Flip Kids is intended for children. The current version does not collect personal data, use advertising or analytics, or include third-party tracking.

Changes to this policy

Future versions may change the app's features or privacy practices. If they do, this policy will be updated before those changes are released.

Questions

For privacy questions or assistance, visit the Memory Flip Kids support page.
